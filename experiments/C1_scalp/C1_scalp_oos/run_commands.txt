Paste these lines into an OPEN Command Prompt (cmd.exe) - no .bat is executed, so Windows
SmartScreen / Mark-of-the-Web does NOT block it and no protection needs to be turned off.
Edit the two SET lines to ABSOLUTE paths (MT5DIR = your separate tester terminal folder;
PKG = where you extracted THIS run folder), then paste the rest. Runs are SEQUENTIAL
(start /wait + ShutdownTerminal=1), and each line checks that its report was produced.
If you prefer the .bat, right-click run_all.bat > Properties > tick 'Unblock' first.

set "MT5DIR=C:\Users\pc\AurvexTester"
set "PKG=<ABSOLUTE path to THIS extracted run folder, e.g. C:\Users\pc\Downloads\C1_scalp_oos>"
start /wait "" "%MT5DIR%\terminal64.exe" /portable /config:"%PKG%\ini\C1_scalp_oos__XAUUSD_20260105_20260327.ini"
