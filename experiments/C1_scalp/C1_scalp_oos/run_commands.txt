Paste these lines into an OPEN Command Prompt (cmd.exe) — no .bat is executed, so Windows
SmartScreen/Mark-of-the-Web does NOT block it and no protection needs to be turned off.
Edit the MT5 path on the first line to YOUR separate tester terminal, then paste the rest.
(Each terminal runs to completion before the next because /config has ShutdownTerminal=1.)
If you prefer the .bat, right-click run_all.bat > Properties > tick 'Unblock' first.

set "MT5=C:\Program Files\MetaTrader 5 Tester"
"%MT5%\terminal64.exe" /config:"experiments/C1_scalp/C1_scalp_oos/ini/C1_scalp_oos__XAUUSD_20260105_20260327.ini"
